Identity & Logomark System

A fluid branding ecosystem structured around curves and historical naming context.

Visual System Assets

Our logo balances three core semantic visual representations to accommodate scalable interface sizes:

  • Wordmark: The primary brand identifier displaying "sam nidhi" utilizing custom Momo Signature script.
  • Initials Monogram: A compressed capsule configuration display token ("sn") integrated down inside dense layouts like app navbars.
  • Icon Mark: A stylized diamond wire representation reflecting the historical derivation of the full name Syamantaka—the divine gemstone assigned to Krishna.

Identity Restrictions

To avoid a cold, corporate future-facing layout footprint, the brand rules prohibit sharp, angular corners or high-weight geometries. All icon manifestations must be positioned over low-contrast color backings to keep an organic, soft screen performance footprint.
