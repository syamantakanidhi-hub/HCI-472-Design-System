Details of Use

Primary capsule fills dictate key workflow paths. Call-to-Action variants scale container min-widths horizontally up to 166px with localized padding settings to focus layout paths.

Accessibility Targets

1. Maintains explicit contrast targets using white-on-wine typography layouts.
2. Formulates touch zones exceeding a 43px ergonomic mobile target frame.
3. Integrates native disabled attributes to accurately modify pointer interaction contexts.
